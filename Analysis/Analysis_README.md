# Analysis

This folder contains the quantitative analysis supporting the Sierra Leone Disaster Risk Reduction & Preparedness project.

## Contents

- `Sierra_Leone_DRR_Quantitative_Analysis_GitHub_Ready.ipynb` — the main reproducible Python analysis notebook.

## Analytical workflow

The notebook covers:

- Data preparation and quality assessment
- Exploratory analysis
- Variable transformations
- Correlation analysis
- Regression modelling
- Regression diagnostics
- Sensitivity analysis
- INFORM risk integration
- Sierra Leone baseline analysis
- International benchmarking
- Coping-capacity analysis
- Investment prioritisation
- Hazard prioritisation
- Peer and structural similarity analysis
- Monitoring, Evaluation and Learning (MEL) benchmarking
- Final analytical outputs

The analysis is designed to translate disaster-risk, preparedness, governance, socioeconomic and health-system evidence into structured decision-support intelligence.
