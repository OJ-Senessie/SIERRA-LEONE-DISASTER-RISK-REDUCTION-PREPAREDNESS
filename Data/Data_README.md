# Data

This folder contains the datasets used to support the Sierra Leone Disaster Risk Reduction & Preparedness analysis.

## Data used

The analysis uses structured disaster-preparedness, socioeconomic, health-system, governance and disaster-impact indicators, alongside INFORM risk data.

## Main dataset

- `V2 DISASTER PREPAREDNESS DATA.xlsx`

The workbook contains the master data used for the quantitative analysis.

## Data handling

The analysis notebook performs data loading, inspection, cleaning, transformation and validation before statistical analysis.

## Reproducibility

Where source datasets are publicly available, their original provenance should be documented in the project README or accompanying methodology documentation.

Do not treat derived analytical outputs as raw source data.
