# Framework

This folder contains the analytical framework underpinning the Sierra Leone Disaster Risk Reduction & Preparedness project.

## S-DRIF

The project develops and applies the **Senessie Disaster Risk Reduction Intelligence Framework (S-DRIF)**.

The framework is designed to move beyond simply ranking countries or measuring risk by organising evidence into a structured decision-support process.

## Contents

- `S-DRIF_Framework.png` — visual representation of the framework.

## Role in the project

S-DRIF provides the conceptual structure connecting evidence, diagnosis, consultation, triangulation, prediction, prescription, decision-making and learning.

The quantitative analysis in the `Analysis` folder provides supporting evidence for this decision-support approach.
